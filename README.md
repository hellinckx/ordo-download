# Summa – Download

**Buchhaltung, die sich selbst erledigt.** Lokale, verschlüsselte Buchhaltungs-App für Österreich.

## Windows

Neueste Version unter [Releases](https://github.com/hellinckx/summa-download/releases/latest) → `Summa_x.y.z_x64-setup.exe` herunterladen und starten.

Windows SmartScreen kann beim ersten Start warnen („Unbekannter Herausgeber“), weil der Installer noch nicht signiert ist: **Weitere Informationen → Trotzdem ausführen**.

## Browser & Handy

Ohne Installation: **https://summa-buchhaltung.netlify.app**

Am Handy den Link öffnen und „Zum Startbildschirm hinzufügen“ wählen – Summa läuft dann wie eine App, Belege lassen sich direkt mit der Kamera fotografieren.

## Datenschutz

Alle Daten bleiben verschlüsselt auf deinem Gerät. Der optionale Sync zwischen Geräten ist Ende-zu-Ende verschlüsselt.
