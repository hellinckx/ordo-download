# Ordo – Windows-App

**Buchhaltung, Projekte und Lager an einem Ort.** Lokale, verschlüsselte Software für Selbstständige und kleine Firmen in Österreich.

## Windows

**Download-Seite: https://ordo-app.at/download/**

Oder direkt: [Ordo-Setup.exe](https://github.com/hellinckx/ordo-download/releases/latest/download/Ordo-Setup.exe) (immer die neueste Version). Installierte Apps holen sich neue Versionen danach von selbst; jedes Update ist signiert und wird vor der Installation geprüft.

Windows SmartScreen kann beim ersten Start warnen („Unbekannter Herausgeber“), weil der Installer noch kein Windows-Zertifikat hat: **Weitere Informationen → Trotzdem ausführen**.

## Browser & Handy

Ohne Installation: **https://ordo-app.at/app/**

Am Handy den Link öffnen und „Zum Startbildschirm hinzufügen“ wählen – Ordo läuft dann wie eine App, Rechnungen lassen sich direkt mit der Kamera fotografieren.

## Datenschutz

Deine Daten liegen verschlüsselt auf deinem Gerät. Den Abgleich zwischen Geräten schaltest du selbst ein – über den Ordo-Server oder deine eigene Datenbank; dort liegen deine Daten ebenfalls nur verschlüsselt. Keine Cookies, kein Tracking. Details: https://ordo-app.at/sicherheit/
